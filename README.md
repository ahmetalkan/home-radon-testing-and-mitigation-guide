# Home Radon Testing and Mitigation Guide

A homeowner reference for running closed-house radon tests, understanding active vs passive mitigation systems, and checking pipe routing across basement, crawl space, and slab foundations, citing US EPA, WHO, and MedlinePlus.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — home radon testing and action-level overview: `https://ahmetalkan.github.io/home-radon-testing-and-mitigation-guide/`
- Subpage — comparing short-term, long-term, and continuous radon tests: `https://ahmetalkan.github.io/home-radon-testing-and-mitigation-guide/short-vs-long-term-radon-test.html`
- Subpage — active vs passive mitigation and essential system components: `https://ahmetalkan.github.io/home-radon-testing-and-mitigation-guide/sub-slab-mitigation-components.html`
- Subpage — matching mitigation layouts to basements, crawl spaces, and slabs: `https://ahmetalkan.github.io/home-radon-testing-and-mitigation-guide/foundation-radon-routing.html`

It cites public pages on [theradonlab.com](https://theradonlab.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
